PDF Password Protection

Encrypt any Odoo PDF report with a password - per report, per partner

Odoo 19 FREE GDPR Ready

The Problem

Odoo sends invoices, payslips, and quotations as unprotected PDFs. Anyone who intercepts the email can open them.

Without this module

🔓

PDF reports are sent in plain text. No encryption. No password. Anyone can open them.

With this module

🔒

PDFs are encrypted with a password. Only the recipient who knows the password can open them.

4 Password Modes

Choose how the password is determined - per report action.

🔑
Static Password

Same password for all PDFs of this report type

🏢
Partner VAT

Password = partner's VAT/tax ID number

📞
Partner Phone

Password = partner's phone or mobile number

✉
Partner Email

Password = partner's email address

All dynamic modes fall back to the static password if the partner field is empty.

How It Works

1
Enable

Go to Settings > Technical > Reports. Open any report action and enable password protection.

2
Configure

Choose password mode: static value, partner VAT, phone, or email. Set a fallback password.

3
Done

Every PDF generated from that report is now encrypted. Recipients need the password to open it.
